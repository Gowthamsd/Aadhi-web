# Aadhi Cement Works (ஆதி சிமெண்ட் ஒர்க்ஸ்)

Official web platform and interactive 3D Compound Wall Studio for **Aadhi Cement Works**, Manjavayal, Tamil Nadu.

## 🌟 Key Features

1. **Bilingual Support (தமிழ் / English)**
   - Seamless one-click instant toggle between English and Tamil.
   - Preference persisted locally across sessions.

2. **Interactive 3D Compound Wall Studio**
   - Live visual simulation of precast RCC compound wall assemblies.
   - Height configuration (5 ft to 8 ft / 5 to 8 plates).
   - Real photographic textures for 7 signature plate designs:
     - Floral Vine (பூ கொடி வேலைப்பாடு)
     - Wave Petals / Scales (அலை வடிவம்)
     - Hexagon Medallion (அறுகோண பூ)
     - Diamond Trellis (வைர கட்டம்)
     - Running Bond Brick Masonry (செங்கல் வடிவம்)
     - Chiseled Rockface (பாறைக்கல் வடிவம்)
     - Classic Smooth Plain / Panthu (சமதள பந்து தட்டு)
   - Tier-by-tier customization, slot swapping, 9 color washes, and preset themes.
   - Direct WhatsApp export with custom configuration breakdown.

3. **Products & Services Showcase**
   - Precast RCC Compound Walls
   - Precast Modular Toilets & Farm Kitchens
   - Concrete Jali / Kirathi (கிராதி) Ventilation Grilles
   - RCC Urai Rings & Slabs (சிமெண்ட் உறை & மூடி)
   - Retail Aggregates: Jelly (ஜல்லி), M-Sand, Cement

4. **Real On-Site Works Gallery**
   - High-resolution real construction site photos from customer installations along the ECR Road.

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (3D CSS perspective transforms, responsive grid/flexbox), JavaScript (ES6+)
- **Storage:** Browser `localStorage` for user preferences and state
- **Design:** Mobile-first, responsive across all screen sizes
- **Fonts:** Space Grotesk, Plus Jakarta Sans, Noto Sans Tamil

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via a local web server (e.g. VS Code Live Server or Python `http.server`).

```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
